# ZeeraK Real Estate & Builders Website

GitHub Pages-ready static website for zeerakrealestateandbuilders.com.

## Deploy
1. Create a GitHub repository.
2. Upload `index.html`, `robots.txt`, `sitemap.xml`, and `assets/`.
3. GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Add the custom domain `zeerakrealestateandbuilders.com`.
5. At your domain registrar, point DNS to GitHub Pages as instructed by GitHub.

## Before launch
Replace/verify:
- Property listings and photos
- Office address
- Business email
- Facebook/Instagram links
- Google Business/Maps link

The current version intentionally does not contain invented property listings, fake reviews, fake statistics, or unverified business claims.
